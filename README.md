# Nova Language
[![Ask DeepWiki](https://devin.ai/assets/askdeepwiki.png)](https://deepwiki.com/simonsarcevic/Nova-Language)

Nova is a simple, dynamically-typed, interpreted programming language built with TypeScript. This repository contains the source code for the Nova interpreter, which includes a lexer, parser, and tree-walk interpreter.

## Features

The current version of Nova supports:
*   **Integer Variable Declaration**: Declare variables of type `int`.
    ```nova
    int a = 10
    ```
*   **Arithmetic Expressions**: Perform addition (`+`) and subtraction (`-`) on integers.
    ```nova
    int result = 15 - 5
    ```
*   **Print Statements**: Output the result of an expression to the console.
    ```nova
    print(result)
    ```

## Getting Started

### Prerequisites
*   Node.js
*   npm (or a compatible package manager)

### Installation

1.  Clone the repository:
    ```sh
    git clone https://github.com/simonsarcevic/nova-language.git
    cd nova-language
    ```

2.  Install the dependencies:
    ```sh
    npm install
    ```

### Usage

You can run Nova programs by passing a `.nv` file to the interpreter.

1.  Create a file named `example.nv` with the following content:
    ```nova
    int a = 3
    int b = 9

    print(b - a)
    ```

2.  Execute the file using the `npm start` script:
    ```sh
    npm start example.nv
    ```

3.  The interpreter will output the result:
    ```
    6
    ```

## Project Structure

The interpreter is organized into several key components within the `src/` directory:

*   `index.ts`: The main entry point for the interpreter. It reads the source file, orchestrates the different components, and executes the program.
*   `lexer.ts`: The **Lexer** (or scanner/tokenizer) which takes the raw source code as a string and converts it into a sequence of tokens.
*   `parser.ts`: The **Parser** which takes the stream of tokens from the lexer and builds an Abstract Syntax Tree (AST) representing the program's structure.
*   `ast.ts`: Defines the TypeScript types and interfaces for the nodes of the Abstract Syntax Tree.
*   `interpreter.ts`: The **Interpreter** which walks the AST generated by the parser and executes the code represented by the tree. It manages variable state and evaluates expressions.
